A simple path forward

Not sure where to begin? Follow these four steps.

  1. Step1

    Learn the kana

    Hiragana first, then katakana. Use the charts, listen to the audio and practice.

  2. Step2

    Climb the kanji

    Work through grades, watch the stroke order and learn readings with related words.

  3. Step3

    Read the grammar

    Understand particles and sentence patterns, then see them in the vocabulary search.

  4. Step4

    Review with flashcards

    Keep track of all your saved kanji cards in one place, with the option to export to Anki, CSV or JSON whenever you need.

For developers

Building something? Use the API.

Hiragana, katakana and kanji data are available over a simple REST API. Grab your API key from your profile and send it in the API-KEY header.

     https://kitsuno.help/api/kanji/1
